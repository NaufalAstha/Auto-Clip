# AUTO CLIP

## Version 1.2 — Agent & Campaign Automation

**Project Name:** Auto Clip
**Version:** v1.2
**Document Type:** Product & Technical Specification
**Base Version:** Auto Clip v1.1
**Development Approach:** Incremental Feature Addition / Extension
**Primary New Capability:** Autonomous Clipping Agent

---

# 1. Document Purpose

Dokumen ini merupakan spesifikasi pengembangan **Auto Clip v1.2** sebagai lanjutan dari Auto Clip v1.1.

Pada v1.0, Auto Clip berfokus pada:

```text
YouTube URL
    ↓
AI Analysis
    ↓
Timestamp
    ↓
Download
    ↓
Video Clip
```

Pada v1.1, Auto Clip berkembang menjadi:

```text
YouTube URL
    ↓
AI Analysis
    ↓
Timestamp
    ↓
Download
    ↓
Face Tracking
    ↓
Smart Crop
    ↓
Auto Caption
    ↓
Final Vertical Clip
```

Pada v1.2, Auto Clip akan berkembang dari sekadar **video processing tool** menjadi **clipping automation system** yang mampu menerima instruksi, memahami reference content, mengakses platform clipping, menganalisis campaign, membuat clip, melakukan publishing, dan menganalisis performa channel.

Konsep utama v1.2:

> **Auto Clip tidak hanya membuat clip. Auto Clip mulai dapat mengambil keputusan dan menjalankan workflow clipping secara mandiri.**

# 3. Main Concept of v1.2

Auto Clip v1.2 memiliki **dua mode utama**:

```text
┌──────────────────────────────┐
│          AUTO CLIP           │
│      User-driven Mode        │
└──────────────────────────────┘

              VS

┌──────────────────────────────┐
│       AUTO CLIP AGENT        │
│     Autonomous Mode          │
└──────────────────────────────┘
```

Kedua mode menggunakan engine yang sama.

Perbedaannya adalah:

> **Siapa yang memberikan context dan mengambil keputusan workflow.**

---

# 4. Mode 1 — Auto Clip

Auto Clip Mode adalah pengembangan dari Auto Clip v1.1.

Pada mode ini:

```text
USER
 ↓
Memberikan Video
 ↓
Memberikan Instruction / Context
 ↓
Auto Clip
 ↓
Generate Clip
 ↓
Final Video
```

User masih menjadi pihak yang menentukan apa yang ingin dibuat.

---

# 5. Mode 2 — Auto Clip Agent

Auto Clip Agent adalah mode autonomous.

Dalam mode ini user tidak perlu memberikan setiap detail proses.

Agent dapat:

```text
Search / Read Campaign
        ↓
Analyze Campaign
        ↓
Score Campaign
        ↓
Determine Worthiness
        ↓
Join Campaign
        ↓
Read Campaign Brief
        ↓
Get Source Material
        ↓
Generate Clip
        ↓
Publish to YouTube Shorts
        ↓
Monitor Performance
        ↓
Analyze Results
        ↓
Use Results as Future Context
```

Konsepnya:

> **User memberikan tujuan, Agent menjalankan workflow.**

---

# 6. Mode Activation

Mode harus dapat dijalankan melalui command line.

Contoh:

```bash
autoclip
```

Default:

```text
Auto Clip Mode
```

Untuk Agent:

```bash
autoclip agent
```

atau:

```bash
autoclip agent mode
```

Implementasi command dapat disesuaikan dengan CLI yang digunakan.

Requirement utamanya:

> User harus dapat memilih mode melalui terminal/CLI tanpa mengubah source code.

# 8. Feature 1 — User Instruction

## 8.1 Objective

User dapat memberikan instruksi tambahan kepada Auto Clip.

Instruksi dapat berupa:

* durasi;
* context;
* target audience;
* gaya hook;
* jenis pembahasan;
* angle;
* jumlah clip;
* target platform;
* batasan tertentu;
* reference content.

Contoh:

```text
Buat clip 30-45 detik.

Ambil bagian yang membahas bagaimana cara menghasilkan
uang dari AI.

Hook harus langsung masuk ke inti pembahasan.

Buat dalam format YouTube Shorts.
```

Instruction tersebut akan menjadi context tambahan untuk AI.

---

# 9. Instruction Processing

Instruction tidak langsung dikirim mentah ke downloader.

Pipeline:

```text
User Instruction
       ↓
Instruction Parser
       ↓
Structured Instruction
       ↓
AI Analysis
       ↓
Timestamp
       ↓
Video Processing
```

Contoh structured instruction:

```json
{
  "duration": {
    "min": 30,
    "max": 45
  },
  "topic": "cara menghasilkan uang dari AI",
  "hook_style": "direct",
  "target_platform": "youtube_shorts",
  "number_of_clips": 3
}
```

Tujuan struktur ini adalah agar instruction dapat dipahami oleh berbagai module tanpa setiap module harus membaca natural language.

---

# 10. Instruction Priority

Jika terdapat beberapa sumber instruction, sistem harus memiliki hierarchy.

Priority:

```text
1. Campaign Rules / Platform Requirements
2. Explicit User Instruction
3. Reference Video Analysis
4. Auto Clip Default Behavior
```

Contoh:

Jika campaign menetapkan:

```text
Duration: 30-60 seconds
```

dan user meminta:

```text
20 seconds
```

maka campaign requirement harus menjadi constraint utama apabila 20 detik tidak diperbolehkan.

Agent tidak boleh menghasilkan output yang melanggar campaign hanya karena user memberikan instruksi yang lebih baru.

# 11. Feature 2 — Link Video Reference (LVF)

User dapat memberikan link video sebagai reference/context.

Supported reference:

```text
YouTube
YouTube Shorts
TikTok
Instagram
dan platform video lain yang dapat diakses melalui browser.
```

Reference video **bukan berarti video tersebut harus di-clip**.

Reference video digunakan untuk memahami:

* style;
* context;
* hook;
* pacing;
* struktur;
* durasi;
* pola opening;
* caption style;
* angle;
* karakteristik content.

---

# 12. LVF Processing

Flow:

```text
Reference URL
      ↓
Platform Detection
      ↓
Gemini
      ↓
Analyze Reference
      ↓
Structured JSON
      ↓
Instruction Context
```

Contoh prompt concept:

```text
Analyze this reference video.

Extract:
- hook structure
- topic/context
- approximate duration
- speaking style
- content angle
- caption characteristics
- opening pattern
- editing pattern
- target audience if identifiable

Return ONLY valid JSON.
```

# 13. LVF JSON Output

Contoh:

```json
{
  "platform": "tiktok",
  "duration_seconds": 42,
  "topic": "AI for business",
  "hook": {
    "type": "curiosity",
    "structure": "Question followed by surprising statement"
  },
  "content_angle": "AI productivity",
  "pacing": "fast",
  "caption_style": "large dynamic subtitle",
  "opening_pattern": "Immediate statement within first 2 seconds"
}
```

JSON ini kemudian menjadi context untuk clip generation.

---

# 14. Reference Video Is Not Instruction Text

Sistem harus membedakan:

```text
User Instruction
```

dengan:

```text
Reference Analysis
```

Contoh:

User:

```text
"Buat clip seperti reference ini."
```

Reference:

```text
https://youtube.com/shorts/xxxxx
```

System:

```text
Instruction:
"Create clip similar in structure/style to reference."

Reference Analysis:
{
   ...
}
```

Jangan menyamakan URL reference sebagai source video yang harus otomatis di-download.

---

# 15. Reference Analysis Must Avoid Literal Copying

Reference video digunakan sebagai context.

System tidak boleh secara default:

* menyalin script;
* menyalin caption;
* menyalin wording;
* menyalin visual secara identik.

Yang diambil adalah **characteristics dan structural pattern**.

Contoh:

```text
Reference:
Hook berupa pertanyaan provokatif.

Output:
Gunakan struktur hook berupa pertanyaan
yang relevan dengan source video.
```

Bukan:

```text
Copy exact hook.
```

# 22. Cookie Storage Security

User meminta cookie disimpan dalam format JSON.

Format data dapat berupa JSON, tetapi **file JSON tidak boleh dianggap sebagai data yang aman hanya karena extension-nya `.json`**.

Cookie/session dapat berfungsi seperti credential.

Recommended:

```text
Browser Cookie
      ↓
Serialize
      ↓
Encrypt
      ↓
JSON
      ↓
Local Storage
```

Jangan menyimpan session cookie sensitif dalam plaintext apabila dapat dihindari.

Contoh:

```json
{
  "platform": "konten",
  "encrypted": true,
  "cookies": "ENCRYPTED_DATA"
}
```

Encryption key tidak boleh disimpan di repository.

# 26. Campaign Criteria

Kriteria utama berdasarkan requirement v1.2:

### Criteria 1 — Budget Remaining

Campaign menarik jika budget belum terlalu banyak digunakan.

Requirement:

```text
Budget Used <= 70%
```

atau:

```text
Budget Remaining >= 30%
```

---

### Criteria 2 — New Campaign

Campaign yang baru launch mendapatkan prioritas.

Reason:

```text
Fresh Campaign
      ↓
Less Competition / Early Opportunity
      ↓
Higher Priority
```

Agent harus menyimpan waktu campaign ditemukan dan, jika tersedia, waktu campaign mulai.

---

### Criteria 3 — YouTube Shorts Supported

Campaign harus memperbolehkan:

```text
YouTube Shorts
```

Jika campaign hanya mengizinkan:

```text
TikTok
Instagram
```

maka campaign tidak memenuhi target distribution Auto Clip Agent v1.2.

---

### Criteria 4 — YouTube Source

Source material campaign harus berasal dari:

```text
YouTube
```

Campaign dengan source yang tidak sesuai requirement tidak diprioritaskan.

---

# 27. Campaign Eligibility

Sebelum scoring, lakukan hard filter.

```text
Campaign
   │
   ├── Active?
   │     └── No → Reject
   │
   ├── Budget <= 70% used?
   │     └── No → Reject
   │
   ├── YouTube Shorts allowed?
   │     └── No → Reject
   │
   ├── Source = YouTube?
   │     └── No → Reject
   │
   └── Passed
         ↓
       Scoring
```

Campaign yang gagal hard requirement tidak perlu mendapatkan score.

---

# 28. Campaign Score

Score digunakan untuk menentukan prioritas.

Contoh model:

```text
Budget Remaining       : 30 points
Campaign Freshness     : 25 points
YouTube Shorts Support : 25 points
YouTube Source         : 20 points
-----------------------------------
Total                  : 100 points
```

Contoh interpretation:

```text
80-100 → High Priority
60-79  → Medium Priority
0-59   → Low Priority
```

Namun score bukan berarti campaign pasti menghasilkan uang.

Score hanya menunjukkan:

> **Seberapa cocok campaign dengan kriteria Auto Clip Agent.**

---

# 29. Important — Score Must Be Configurable

Scoring jangan hard-code secara permanen.

Contoh:

```python
CAMPAIGN_SCORE = {
    "budget": 30,
    "freshness": 25,
    "youtube_shorts": 25,
    "youtube_source": 20
}
```

Dengan demikian weighting dapat diubah tanpa rewrite campaign engine.

---

   ↓

# 32. Campaign Join Safety

Sebelum klik "Join Campaign", Agent harus memastikan:

* campaign masih active;
* campaign belum pernah diikuti;
* account masih valid;
* platform target sesuai;
* source material tersedia;
* tidak ada requirement yang belum dipenuhi.

Jika terdapat perubahan antara waktu scoring dan waktu join:

```text
Re-check Campaign
      ↓
Changed?
 /       \
Yes       No
 |         |

```

# 101. Non-Goals of v1.2

Fitur berikut belum menjadi requirement utama:

* TikTok automatic publishing;
* Instagram automatic publishing;
* automatic financial withdrawal;
* automatic account registration;
* bypass CAPTCHA;
* bypass anti-bot system;
* bypass platform security;
* facial identity recognition;
* guaranteed viral prediction;
* guaranteed campaign profit;
* automatic deletion of published content;
* automatic manipulation of views/engagement;
* artificial engagement generation.

Agent hanya mengotomatisasi workflow clipping yang legitimate dan diperbolehkan oleh platform.

# 102. Final Product Objective

Auto Clip v1.2 harus membuktikan bahwa sistem dapat melakukan dua jenis workflow:

### User-Driven Workflow

```text
User gives source
        +
User gives context
        ↓
Auto Clip understands
        ↓
Auto Clip creates clip
```

### Agent-Driven Workflow

```text
Agent finds opportunity
        ↓
Agent evaluates campaign
        ↓
Agent joins campaign
        ↓
Agent understands brief
        ↓
Agent finds clip
        ↓
Agent edits clip
        ↓
Agent publishes
        ↓
Agent analyzes result
        ↓
Agent improves future decisions
```

**Core objective:**

> **Auto Clip v1.2 mengubah Auto Clip dari video clipping tool menjadi autonomous clipping workflow yang mampu menjalankan proses dari campaign discovery sampai content publishing dan performance analysis, tanpa melakukan perubahan fundamental terhadap architecture Auto Clip v1.1.**
