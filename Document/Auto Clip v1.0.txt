# AUTO CLIP

## MVP Project Specification

**Project Name:** Auto Clip
**Version:** MVP v1.0
**Document Type:** Product & Technical Specification
**Primary Purpose:** Otomatisasi pembuatan video clip dari video YouTube berdasarkan timestamp hasil analisis AI.

---

# 1. Project Overview

**Auto Clip** adalah sebuah tools berbasis Python yang dirancang untuk mengotomatisasi proses pembuatan video clip dari video YouTube berdurasi panjang.

Pada MVP, user cukup memberikan **URL video YouTube**. Selanjutnya Auto Clip akan:

1. Menerima URL YouTube dari user.
2. Membuka dan menganalisis video menggunakan Gemini AI melalui browser automation dengan Selenium.
3. Meminta Gemini mengidentifikasi bagian video yang berpotensi menjadi clip berdasarkan kriteria yang telah ditentukan.
4. Menerima hasil analisis Gemini dalam format JSON yang berisi timestamp.
5. Menggunakan timestamp tersebut untuk menentukan bagian video yang perlu di-download.
6. Menggunakan `yt-dlp` untuk mengambil bagian video berdasarkan timestamp, tanpa perlu menyimpan seluruh video secara lokal.
7. Menghasilkan file video clip yang siap digunakan.

### High-Level Flow

```text
User
  │
  ▼
Input YouTube URL
  │
  ▼
Auto Clip
  │
  ├── Validate URL
  │
  ▼
Selenium Browser Automation
  │
  ▼
Gemini AI
  │
  ├── Analyze Video
  │
  └── Return Timestamp JSON
  │
  ▼
Timestamp Validation
  │
  ▼
yt-dlp
  │
  ├── Download only required segment
  │
  ▼
Generated Video Clip
  │
  ▼
Output
```

---

# 2. MVP Objective

Tujuan utama MVP adalah membuktikan bahwa Auto Clip dapat melakukan proses berikut secara otomatis:

> **YouTube URL → AI Analysis → Timestamp → Download Segment → Video Clip**

MVP tidak ditujukan untuk memiliki seluruh fitur editing video atau content automation.

Fokus utama MVP adalah memastikan pipeline dasar berjalan secara stabil dan dapat menghasilkan clip berdasarkan timestamp yang diberikan AI.

### C. Structured AI Output

Output Gemini harus menggunakan format JSON yang telah ditentukan.

Contoh:

```json
{
  "clips": [
    {
      "start": "00:12:35",
      "end": "00:13:42",
      "title": "Interesting Discussion",
      "reason": "Contains a strong and engaging statement."
```

Output harus melalui proses validation sebelum digunakan oleh downloader.

# 4. Timestamp Specification

Timestamp merupakan komponen penting dalam pipeline Auto Clip.

Format timestamp MVP:

```text
HH:MM:SS
```

Contoh:

```text
00:05:32
01:24:17
02:13:45
```

Untuk setiap clip harus terdapat:

```text
start
end
```

Contoh:

```json
{
  "start": "00:05:32",
  "end": "00:06:48"
}
```

### Rules

1. `start` harus lebih kecil daripada `end`.
2. Timestamp tidak boleh negatif.
3. Timestamp tidak boleh melebihi durasi video.
4. Durasi clip harus berada dalam batas yang telah ditentukan oleh konfigurasi Auto Clip.
5. JSON harus dapat di-parse secara otomatis.
6. Jika Gemini menghasilkan JSON invalid, Auto Clip harus menangani error tersebut.
7. Jangan langsung mengirim output Gemini ke `yt-dlp` tanpa validation.

# 5. AI Analysis Flow

## 5.1 Browser Automation

Selenium digunakan untuk mengotomatisasi browser.

Flow:

```text
Start
  │
  ▼
Launch Browser
  │
  ▼

  │
  ▼

  │
  ▼

  │
  ▼

  │
  ▼

  │

```

---

## 5.2 Prompt Engineering

Prompt Gemini harus dibuat seketat mungkin.

Gemini harus diberikan instruksi untuk:

* menganalisis video;
* mencari bagian yang relevan untuk clip;
* menentukan timestamp;
* menggunakan format timestamp yang telah ditentukan;
* mengembalikan JSON;
* tidak memberikan response tambahan di luar JSON.

Contoh struktur prompt:

```text
Analyze the provided video and identify the most suitable segments
for short-form video clips.

For each clip provide:

- start timestamp
- end timestamp
- title
- reason

Timestamp format must be HH:MM:SS.

Return ONLY valid JSON.

Required format:

{
  "clips": [
    {
      "start": "HH:MM:SS",
      "end": "HH:MM:SS",
      "title": "string",
      "reason": "string"
    }
  ]
}
```

Prompt final dapat dikembangkan lebih lanjut setelah dilakukan testing terhadap kualitas output Gemini.

# 6. JSON Processing

Setelah Selenium mendapatkan response dari Gemini, Auto Clip harus melakukan:

```text
Gemini Response
      │
      ▼
Extract Text
      │
      ▼
Clean Response
      │
      ▼
JSON Parse
      │
      ▼
Schema Validation
      │
      ▼
Timestamp Validation
      │
      ▼
Approved Clip Data
```

Jika JSON tidak valid:

```text
Invalid JSON
     │
     ▼
Retry / Request Correction
     │
     ▼
Gemini
```

Jumlah retry harus dibatasi agar proses tidak masuk infinite loop.

Contoh konfigurasi:

```python
MAX_AI_RETRY = 3
```

# 7. YouTube Video Processing

Setelah timestamp berhasil diperoleh, Auto Clip masuk ke tahap download.

Library yang digunakan:

```text
yt-dlp
```

Tujuan utama:

> Mendownload hanya bagian video yang dibutuhkan berdasarkan timestamp, bukan mendownload keseluruhan video terlebih dahulu.

Contoh:

```text
Original Video
00:00:00 ───────────────────────────── 02:00:00

                    │────────│
                    00:42:10 00:43:35
                       Clip
```

Auto Clip hanya membutuhkan:

```text
00:42:10 → 00:43:35
```

---

# 8. yt-dlp Processing

`yt-dlp` digunakan sebagai downloader utama.

Pipeline:

```text
Timestamp JSON
     │
     ▼
Convert Timestamp
     │
     ▼
Build yt-dlp Configuration
     │
     ▼
Download Required Segment
     │
     ▼
Process / Merge Audio & Video
     │
     ▼
Output MP4
```

Contoh data internal:

```python
clip = {
    "start": "00:42:10",
    "end": "00:43:35"
}
```

Data tersebut kemudian dikonversi ke format yang dibutuhkan downloader.

# 13. Error Handling

Error handling wajib menjadi bagian dari MVP.

## 13.1 Invalid YouTube URL

```text
ERROR_INVALID_URL
```

Response:

```text
Invalid YouTube URL.
```

---

## 13.2 Selenium Error

Kemungkinan:

* browser gagal dibuka;
* Gemini tidak dapat diakses;
* element tidak ditemukan;
* page timeout;
* browser crash.

System harus mencatat error ke log.

---

## 13.3 Gemini Response Error

Kemungkinan:

* response kosong;
* JSON invalid;
* format tidak sesuai;
* timestamp tidak valid;
* Gemini tidak memberikan timestamp.

System harus memiliki mekanisme retry.

Contoh:

```text
Attempt 1
   ↓
Invalid response
   ↓
Attempt 2
   ↓
Invalid response
   ↓
Attempt 3
   ↓
FAIL
```

---

## 13.4 Download Error

Kemungkinan:

* video tidak tersedia;
* video private;
* video membutuhkan authentication;
* format tidak tersedia;
* network error;
* `yt-dlp` gagal;
* segment extraction gagal.

Error harus dicatat dan proses harus berhenti secara terkontrol.

MVP harus memperhatikan waktu proses.

Pipeline terdiri dari beberapa proses yang berpotensi lambat:

```text
Browser startup
      +
Gemini analysis
      +
Response parsing
      +
YouTube processing
      +
Video download
```

Karena itu, setiap step sebaiknya memiliki timestamp/log duration.

Contoh:

```text
URL Validation      : 0.2s
Browser Startup     : 2.4s
Gemini Analysis     : 35.8s
JSON Processing     : 0.1s
Clip Download       : 18.2s
----------------------------
Total               : 56.7s
```

Data ini penting untuk optimasi pada versi berikutnya.

# 19. Security & Reliability Considerations

Walaupun Auto Clip merupakan MVP, beberapa hal harus diperhatikan.

### Browser Session

Jangan menyimpan credential Gemini secara hard-code di source code.

### User Input

URL dari user harus divalidasi sebelum diproses.

### File System

Output filename harus dikontrol oleh aplikasi.

Jangan menggunakan raw user input sebagai filename tanpa sanitization.

### Temporary Files

File sementara harus dihapus setelah proses selesai jika sudah tidak dibutuhkan.

### Process Isolation

Jika command external seperti `yt-dlp` atau FFmpeg dijalankan melalui subprocess, input command harus dibangun dengan aman dan tidak langsung dieksekusi sebagai arbitrary shell command.

# 27. Core Principle

Auto Clip MVP harus mengikuti prinsip:

> **Build the smallest reliable pipeline that proves the core product value.**

Jangan menambahkan fitur hanya karena secara teknis fitur tersebut bisa dibuat.

Prioritas MVP adalah:

```text
RELIABILITY
     ↓
CORRECTNESS
     ↓
PERFORMANCE
     ↓
USER EXPERIENCE
     ↓
ADDITIONAL FEATURES
```

Core product yang harus dibuktikan terlebih dahulu adalah:

> **User memberikan YouTube URL → Auto Clip menemukan timestamp → Auto Clip menghasilkan clip video yang benar.**

Jika pipeline tersebut belum stabil, fitur lain sebaiknya ditunda.
